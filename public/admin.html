Tài Liệu Tích Hợp API Quản Trị & Khách Hàng

Xem và sao chép cấu trúc endpoint, chữ ký HMAC-SHA256, và mã nguồn tích hợp vào ứng dụng LTVStudio.

Mở Trang Đầy Đủ
PRODUCTION https://ltv-tools.vercel.app
LOCAL VPS http://localhost:8080

1. Kiểm Tra Phiên Bản Cập Nhật (OTA)

GET /api/transform/version

Trả về phiên bản phần mềm mới nhất, URL tải bộ cài Windows Setup và nội dung nhật ký cập nhật.

curl -s https://ltv-tools.vercel.app/api/transform/version

2. Xác Thực Bản Quyền & Khóa Thiết Bị (HWID)

POST /api/auth/verify

Client máy tính gửi mã bản quyền và mã máy (Machine ID / HWID) để mở khóa tính năng.

curl -X POST https://ltv-tools.vercel.app/api/auth/verify \
  -H "Content-Type: application/json" \
  -d '{"licenseKey": "LTV-PRO-8888-9999-LIFETIME", "machineId": "WIN-UUID-4A7F-9B21"}'

3. Cổng Tra Cứu Công Khai (Public Lookup)

GET /api/license/lookup?key=...

Tra cứu thông tin gói cước, hạn dùng và mã phần cứng được che (Masked HWID) bảo mật quyền riêng tư.

curl -s "https://ltv-tools.vercel.app/api/license/lookup?key=LTV-PRO-8888-9999-LIFETIME"

4. Danh Mục API Quản Trị Hệ Thống (Admin Endpoints)

POST /api/admin/login
Đăng nhập quản trị viên & nhận Bearer Token
GET /api/admin/stats
Chỉ số thống kê KPI toàn hệ thống
GET /api/admin/licenses
Danh sách key có bộ lọc trạng thái và gói
POST /api/admin/licenses/create
Phát hành key đơn hoặc tạo hàng loạt
PUT /api/admin/licenses/:key
Cập nhật, gia hạn ngày, reset mã HWID
DELETE /api/admin/licenses/:key
Xóa vĩnh viễn key khỏi cơ sở dữ liệu
