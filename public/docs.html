Tổng Quan Kiến Trúc API

Hệ thống LTVStudio Cloud Web API cung cấp các dịch vụ đám mây thời gian thực cho ứng dụng máy tính LTVStudio, các công cụ biên dịch video và cổng quản trị bản quyền. Toàn bộ API được thiết kế theo chuẩn RESTful, trả về định dạng JSON UTF-8 với thời gian phản hồi dưới 50ms.

Máy Chủ Production & Development:

PRODUCTION https://ltvstudio-web-api.vercel.app
LOCAL VPS http://localhost:8080

Chuẩn Bảo Mật HMAC-SHA256 & Anti-Replay

Mọi yêu cầu xác thực bản quyền từ máy tính khách hàng được bảo vệ nghiêm ngặt bằng cơ chế Hardware ID Binding và chữ ký điện tử HMAC-SHA256 để ngăn chặn giả mạo gói tin (Man-In-The-Middle) và tấn công phát lại (Replay Attacks).

Yêu Cầu Của Gói Tin Xác Thực:

  • timestamp: Unix timestamp hiện tại (mili-giây). Hệ thống từ chối gói tin nếu sai lệch quá 5 phút.
  • nonce: Chuỗi ngẫu nhiên 16–32 ký tự, dùng 1 lần duy nhất để chống phát lại.
  • signature: Chữ ký HMAC-SHA256 tính từ chuỗi ${licenseKey}:${machineId}:${timestamp}:${nonce}.
  • validateHwid: Chuỗi HWID máy tính hợp lệ (tối thiểu 6 ký tự, không chấp nhận chuỗi rỗng hoặc UNKNOWN).

1. Kiểm Tra Cập Nhật Phiên Bản (OTA)

Client desktop gọi endpoint này khi khởi động hoặc khi người dùng nhấp "Kiểm tra cập nhật".

GET /api/transform/version 
curl -s https://ltvstudio-web-api.vercel.app/api/transform/version

Ví Dụ Phản Hồi Thành Công (HTTP 200):

{
  "version": "1.0.0",
  "releaseDate": "2026-10-15",
  "forceUpdate": false,
  "downloadUrl": "https://ltvstudio-web-api.vercel.app/downloads/LTVStudio-Windows-Setup.exe",
  "changelog": "• Ra mắt phiên bản thương mại chính thức\n• Nâng cấp AI Voice Engine\n• Tích hợp bản quyền HWID đám mây",
  "minSupportedVersion": "1.0.0"
}

2. Xác Thực Bản Quyền & Khóa Thiết Bị (HWID)

Client máy tính gửi mã bản quyền và mã nhận diện phần cứng (Machine ID / HWID) để mở khóa tính năng. Lần đầu tiên xác thực, hệ thống sẽ tự động gán vĩnh viễn với thiết bị đó.

POST /api/auth/verify 
curl -X POST https://ltvstudio-web-api.vercel.app/api/auth/verify \
  -H "Content-Type: application/json" \
  -d '{
    "licenseKey": "LTV-PRO-8888-9999-LIFETIME",
    "machineId": "WIN-UUID-4A7F-9B21-5089"
  }'

Ví Dụ Phản Hồi Thành Công (HTTP 200):

{
  "isValid": true,
  "licenseKey": "LTV-PRO-8888-9999-LIFETIME",
  "plan": "LIFETIME",
  "status": "ACTIVE",
  "isBound": true,
  "expiresAt": null,
  "features": ["FULL_STUDIO_ACCESS", "OFFLINE_DUBBING", "AUTO_UPDATES"],
  "token": "hmac_signature_token_here",
  "timestamp": 1792051200000,
  "message": "Xác thực bản quyền thành công! Chào mừng bạn đến với LTVStudio Pro."
}

3. Cổng Tra Cứu Công Khai (Public Lookup)

Cho phép khách hàng hoặc đại lý kiểm tra trạng thái của mã bản quyền mà không làm lộ các thông tin nhạy cảm. Mã thiết bị phần cứng sẽ được tự động che (ví dụ: WIN-****-001).

GET /api/license/lookup?key=... 
curl -s "https://ltvstudio-web-api.vercel.app/api/license/lookup?key=LTV-PRO-8888-9999-LIFETIME"

Ví Dụ Phản Hồi (HTTP 200):

{
  "exists": true,
  "key": "LTV-PRO-8888-9999-LIFETIME",
  "plan": "LIFETIME",
  "status": "ACTIVE",
  "isBound": true,
  "maskedMachineId": "WIN-****-001",
  "customer": "Khách hàng VIP",
  "daysLeft": "Vĩnh viễn",
  "expiresAt": "Không giới hạn (Lifetime)"
}

4. API Quản Trị Hệ Thống (Admin APIs)

Dành riêng cho bảng điều khiển quản trị viên. Toàn bộ yêu cầu quản trị bắt buộc phải truyền header xác thực Authorization: Bearer <admin_session_token> hoặc x-admin-key: <secret>.

POST /api/admin/login
Đăng nhập lấy session token (24h)
GET /api/admin/stats
Xem chỉ số thống kê KPI
GET /api/admin/licenses
Lấy toàn bộ danh sách key
POST /api/admin/licenses/create
Phát hành key đơn hoặc hàng loạt
PUT /api/admin/licenses/:key
Cập nhật, gia hạn, reset HWID
DELETE /api/admin/licenses/:key
Xóa key khỏi cơ sở dữ liệu

5. Bảng Tiêu Chuẩn Mã Lỗi HTTP

Mã HTTP Tên Mã Ý Nghĩa / Nguyên Nhân
200 OK Success Yêu cầu đã được xử lý thành công, trả về dữ liệu tương ứng.
400 Bad Request Invalid Payload Thiếu tham số bắt buộc hoặc định dạng license key / HWID không hợp lệ.
401 Unauthorized Invalid Auth Chữ ký HMAC không khớp hoặc thiếu token phiên đăng nhập quản trị.
403 Forbidden Device Mismatch / Locked Bản quyền đã bị khóa hoặc cố gắng kích hoạt trên thiết bị khác với máy đã đăng ký.
429 Too Many Requests Rate Limited Hệ thống phát hiện brute-force và tạm thời khóa IP trong 10 phút.
